חיבור Articulate Storyline 360 ל-Google Sheets בקלות וללא ידע בתכנות

מחולל הסקריפטים לסטוריליין (Storyline to Google Sheets Script Generator) מאפשר למפתחי הדרכה, מעצבי למידה דיגיטלית וארגונים לייצא ולשמור משתנים מתוך לומדות וקורסים שפותחו ב-Articulate Storyline 360 ישירות לתוך גיליון Google Sheets בזמן אמת – ללא צורך בכתיבת קוד ידנית או במערכת LMS מורכבת.

איך מייצאים משתנים מסטוריליין לגוגל שיטס ב-3 שלבים פשוטים?

  1. 1

    הגדרת שמות המשתנים מ-Storyline

    בוחרים את מספר המשתנים (עד 50 משתנים בפרויקט) ומזינים את שמותיהם בדיוק כפי שהוגדרו ב-Storyline 360 (Case Sensitive).

  2. 2

    הטמעת קוד Google Apps Script

    מעתיקים את קוד ה-Apps Script שנוצר אוטומטית, מדביקים בגיליון ה-Google Sheets תחת Extensions > Apps Script ומפרסמים כ-Web App.

  3. 3

    הדבקת קוד ה-JavaScript בלומדה

    מזינים את כתובת ה-Web App URL במחולל, מעתיקים את קוד ה-JavaScript המוכן ומדביקים אותו בטריגר Execute JavaScript ב-Storyline.

שאלות נפוצות (FAQ) – ייצוא נתונים מ-Storyline ל-Google Sheets

למה כדאי לחבר לומדה ב-Storyline 360 ל-Google Sheets?

חיבור סטוריליין לגוגל שיטס מאפשר לאסוף נתוני לומדים בזמן אמת גם כאשר הלומדה מופצת כקישור Web רגיל (ללא מערכת LMS) או כאשר רוצים לשמור מידע שמערכות LMS לא תמיד מציגות בנוחות – כגון תשובות לשאלות פתוחות, משובים, ציוני ביניים, זמני למידה, פרטי התקשרות וניסיונות מענה.

האם נדרש ידע מוקדם ב-JavaScript או ב-Google Apps Script?

לא נדרש שום ידע בתכנות. המחולל מייצר עבורכם באופן אוטומטי את שני הסקריפטים המתאימים בדיוק למשתנים שלכם: קוד צד-שרת ל-Google Apps Script (כולל יצירת כותרות עמודות וחותמת זמן Timestamp אוטומטית) וקוד צד-לקוח ב-JavaScript המשתמש בפקודת GetPlayer().GetVar() לשליחת הנתונים מהלומדה.

אילו סוגי משתנים ניתן לשלוח מסטוריליין לגוגל שיטס?

ניתן לייצא את כל סוגי המשתנים ב-Articulate Storyline 360: משתני טקסט (Text), משתני מספר (Number) ומשתני אמת/שקר (True/False). בנוסף, הסקריפט מוסיף אוטומטית עמודת תאריך ושעה לכל שורה שמתווספת לגיליון.

איך מגדירים נכון את הרשאות ה-Web App ב-Google Apps Script?

בחלון ה-Apps Script של הגיליון לוחצים על Deploy > New deployment, בוחרים בסוג Web app, מגדירים תחת Execute as את החשבון שלכם (Me), ותחת Who has access בוחרים Anyone כדי שהלומדה תוכל לשלוח נתונים מכל מכשיר או דפדפן ללא חסימת הרשאות.
